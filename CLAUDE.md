# Omni Odyssey Project

This repository contains the Omni Odyssey web application.

## Project boundary

- Treat this directory as the repository root.
- Do not create or modify files outside this repository.
- Before major work, confirm that package.json and this CLAUDE.md are present.
- Do not modify unrelated files.
- Do not install dependencies without explaining why they are needed.

## Workflow

- Inspect existing code before editing.
- Use plan mode for large features.
- Implement one vertical feature at a time.
- Run lint, type checking, and build checks after substantial changes.
- Never report completion while the production build is failing.
